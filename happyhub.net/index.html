API Reference

Everything you can build with the replicatedscripts library.

Global Configuration

A single table, API.Config, that controls game compatibility and the key system.

API.Config.KeySystem
  • Enabled — disables the entire key flow when false.
  • Provider — display name shown in the auth window.
  • URL — link copied to clipboard when the user clicks Get Key.
  • ExpectedKey — exact key the user must paste to unlock the hub.

Root API

API:CreateWindow(title, subtitle)

Creates the main window and returns the window object used to build everything else.

API:Notify(text, duration)

Shows an animated toast notification in the top-right corner.

API:SetTheme(name) · API:GetTheme() · API:GetThemes()

Manage the active theme at runtime.

API:GetControl(name) · API:GetControlsByName(name)

Look up registered controls by name.

Window Methods

window:CreateTab(name, iconId)

Creates a sidebar tab and returns the tab object.

window:CreateLabel(tab, text)

Accent-colored section header with a typewriter animation.

window:CreateParagraph(tab, text)

Informational paragraph with automatic word-wrap.

window:CreateImageCard(tab, config)

Card with image, title, subtitle and description.

window:CreateButton(tab, text, callback, tooltip)

Clickable button with optional tooltip.

window:CreateToggle(tab, text, default, callback, desc, tooltip)

Pill toggle with a check icon (ON) or X icon (OFF) inside the knob.

window:CreateSlider(tab, text, min, max, default, callback, tooltip, forceInt)

Slider row with auto int/float detection and live value display.

window:CreateDropdown(tab, text, options, default, callback, tooltip)

Single-select dropdown. The list always opens downward.

Config System

window:SetConfigSnapshot(fn) · SetConfigApply(fn)

Register functions that return the current settings table and apply loaded settings.

window:BuildConfigPage()

Creates a built-in Settings tab with theme dropdown, storage path TextBoxes, config save/load/delete/refresh buttons, reset-to-defaults, and a Delete UI button.

Mobile Helpers

window:AddMobileButton(config) · ClearMobileButtons()

Adds floating buttons that only appear on mobile (max 3).

Visibility & Teardown

window:HideUI() · ShowUI() · ToggleUI() · Destroy()

Control whether the hub is visible. Destroy disconnects every tracked connection and removes the ScreenGui.
